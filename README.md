## Selected projects

### ChainSecDB

[github.com/rootkit-io/ChainSecDB](https://github.com/rootkit-io/ChainSecDB)

Blockchain security intelligence backend built around provenance and verifiable source evidence.

- FastAPI + PostgreSQL
- validated document ingestion
- SHA-256 content fingerprinting
- database-enforced deduplication
- source provenance and exact evidence preservation
- Alembic migrations and PostgreSQL-backed testing

The long-term goal is to connect audit findings, vulnerabilities, exploits, and incident research without making AI-generated analysis the source of truth.

### Xandeum pNode Analytics Backend

[github.com/rootkit-io/Xandeum-backend](https://github.com/rootkit-io/Xandeum-backend)

Backend for real-time infrastructure monitoring and analytics.

Built with TypeScript, Fastify, PostgreSQL, Redis, WebSockets, scheduled workers, alerting, historical metrics, and API rate limiting.

### ZybeAuditTool

[github.com/rootkit-io/ZybeAuditTool](https://github.com/rootkit-io/ZybeAuditTool)

Website auditing backend built with hostile input in mind.

Includes SSRF-resistant URL handling, DNS and redirect validation, PostgreSQL, Prisma, rate limiting, privacy-aware logging, safe HTML fetching, and AI-assisted reports with deterministic fallbacks.
